# Журнал робіт FuzzHelm

Щоденні записи — заготовка тексту звіту. Формат: дата — модуль — що зроблено, яке рішення, чому.

## 2026-09-18 — фаза 0 (плацдарм)

Робочий репозиторій створено поза iCloud (`~/dev/fuzzhelm`), бо синхронізація iCloud псує volume
PostgreSQL. Каркас пакетів за §9 брифінгу; залежності через `uv` (Python 3.12). Реалізовано ядро
`core`: канонічні DTO (pydantic, frozen, extra=forbid), порти `Clock/IdGenerator/MarketFeed/ExecutionVenue`,
детерміністичний генератор UUID з seed (BLAKE2b від лічильника), канонічна серіалізація з рекурсивним
предвалідатором float, журнал подій із ланцюгом BLAKE2b-256. Дві точки конвертації Decimal↔float
(`features/convert.py`, `sizing/convert.py`) і три архітектурні тести (межа детермінізму, межа типів,
allowlist testnet-хостів) — пишуться першими, щоб усі наступні модулі з самого початку їм підкорялися.
Записано живу WS-сесію Binance USDⓈ-M: 4-хвилинний зразок для швидких тестів і 45-хвилинну сесію для демо.
Під час запису виявлено, що Binance розділив потоки на `/market` і `/public` (див. deviations D-01).
