# MLP-автокодувальник аномалій: ROC-AUC на розмічених ін'єкціях (справжнє IS-вікно)

Згенеровано `uv run python scripts/train_anomaly_mlp.py --seed 20260918 --rate 0.02 --extra-seeds 1,2,3,4,5 --symbol ETHUSDT --is-days 15 --holdout-days 5 --out docs/figures/quality_mlp_rocauc_ETHUSDT.md`. Автор: Андрій Жук, 2026. Процедура — `fuzzhelm.quality.anomaly_eval.evaluate_injections`; усі числа нижче — з цього прогону.

## Дані

* Джерело: робоча БД (PostgreSQL, порт 5442, таблиця `candle`, лише SELECT роллю fuzzhelm_app); символ ETHUSDT, tf 1m, закриті свічки.
* Навчання (IS): дні 1–15 `[2026-08-04T00:00:00Z, 2026-08-19T00:00:00Z)` — 21600 барів; `dataset_hash` (колонки c, h, l, o, t_ns, v) `f7ae8ca7bfb7d9c5c9aa548a02b1e23a0081097489a639cfd4e0eb9b9824b2ed`.
  Хеш НЕ збігається з хешем вікна калібрування МФ у `data/calibration_manifest.json` (`9156616db47020ca…`): це ті самі бари.
* Відкладений відрізок (held-out): дні 16–20 `[2026-08-19T00:00:00Z, 2026-08-24T00:00:00Z)` — 7200 барів; `dataset_hash` `9e92d163e74aa04b5f9f1aa7bda0d7c4bf0fbc40be5eedea0d2b802ca790b025`. На ньому нічого не підбирається: архітектура 8-3-8 задана наперед (брифінг §3), 5-3-5 — порівняння, seed — `FUZZHELM_SEED`.
* «Нормальні» бари навчання: справжні бари IS без ін'єкцій; вилучаються лише бари зі зламаними структурними інваріантами або синтетичні (добір прогалин) — вилучено 0 векторів (синтетичних свічок у вікні: 0). Справжні екстремальні бари не вилучаються: розмітки для них немає, а відбір власним скором моделі був би коловим.
* Векторів ознак: навчання 21382 (після прогріву екстрактора, 218 барів), негативів held-out 7200; σ(Δlog p) на навчанні = 0.000403.
* Ознаки 8-3-8: dlogp, log_rg_atr, log_v_vbar, bw_pct, abs_z, log_n_nbar, body, open_gap; 5-3-5 — перші п'ять (вектор брифінгу §5.17).
* Модель: StandardScaler → MLPRegressor(hidden_layer_sizes=(3,), activation=tanh, max_iter=500, random_state=20260918); скор — ‖x − x̂‖² у стандартизованому просторі; поріг — q₉₉ навчальних скорів.

## Ін'єкції (типи й частоти)

Кожен тип вноситься в 144 випадкових позицій held-out (частота 0.02 на тип = 144/7200 барів; разом 576 позитивних на 7200 негативних), по одній: стан екстрактора до бару t — з чистого ряду, змінюється лише бар t.

| тип | що спотворюється | амплітуда m | позицій |
|---|---|---|---|
| price_spike | стрибок закриття: c = c₋₁·(1 ± m), тінь розширюється до c | 0.3…2 % | 144 |
| wick | «товстий палець»: h = max(o, c)·(1 + m), тіло без змін | 0.3…2 % | 144 |
| volume_burst | сплеск активності: v, qv і кількість угод × m, ціни без змін | ×5…×30 | 144 |
| frozen | застиглий бар: o = h = l = c = c₋₁, v = 0, угод 0 | — | 144 |
