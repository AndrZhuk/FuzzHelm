# MLP-автокодувальник аномалій: ROC-AUC на розмічених ін'єкціях

Згенеровано `scripts/train_anomaly_mlp.py --seed 20260918 --per-kind 150`. Автор: Андрій Жук, 2026.

* Дані: 3000 справжніх закритих 1m-барів BTCUSDT (`fixtures/rest/binance_klines.json.gz`).
* IS (навчання, лише нормальні бари): перші 1800 барів → 1582 векторів ознак (після прогріву екстрактора).
* OOS: 1200 барів → 1200 негативних прикладів; по 150 позитивних на кожен тип аномалії (вносяться по одній у чистий ряд).
* Модель: StandardScaler → MLPRegressor(hidden_layer_sizes=(3,), activation=tanh, max_iter=500, random_state=20260918); скор — ‖x − x̂‖², поріг — q₉₉ навчальних скорів.
* σ(Δlog p) на IS = 0.000453 (для масштабу амплітуд).
* Ознаки 8-3-8: dlogp, log_rg_atr, log_v_vbar, bw_pct, abs_z, log_n_nbar, body, open_gap; 5-3-5 — перші п'ять (вектор брифінгу §5.17).
